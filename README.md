# Car Wash Website

Modern, responsive commercial-style car wash website with:

- Professional navigation (desktop + mobile drawer)
- Services and pricing sections
- Before/after showcase and gallery
- Merchandise cards
- Booking form UI with front-end validation
- Location/contact and full commercial footer

## Run locally

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Content placeholders

Where business data is not available (pricing, address, contact details, testimonials), clear placeholders are included for later replacement with real information.
